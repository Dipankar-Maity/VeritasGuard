VERITASGUARD — MILESTONE 2 INSTALLATION (WINDOWS 11)
==================================================

1. Keep your existing local .env secret file. It is NOT included in this ZIP.
2. Close the running Streamlit terminal (Ctrl+C) before replacing files.
3. If using VeritasGuard_Milestone2_Update.zip, extract its contents DIRECTLY into:
   D:\Project\Open Elective Project\VeritasGuard
   Allow overwrite for existing app.py, requirements.txt and README.md.
   It will add image_analyzer.py and tests\test_image_analyzer.py.
4. In Antigravity open a fresh PowerShell terminal in that folder.
5. Install/update the required packages (no AI coding agent needed):
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
6. Run actual local automated tests:
   .\.venv\Scripts\python.exe -m pytest -v -s
7. Start VeritasGuard:
   .\.venv\Scripts\python.exe -m streamlit run app.py
8. Visit http://localhost:8501 and select:
   Live AI Analysis -> Screenshot Image -> upload a synthetic/redacted PNG/JPEG
   Review the preview without a Gemini call.
9. If ready, click Analyze ONCE for one live image test.

install the full google-genai/streamlit packages. We ran 30 unit tests
